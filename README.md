# TCS Interactive React and Node.js Assignment

## Tech Stack
- Frontend: React, Vite
- Backend: Node.js, Express
- Authentication: JWT

## Steps to Run Locally

```bash
# Backend
cd server
npm install
cp .env.example .env
node server.js

# Frontend
cd ..
cd client
npm install
npm run dev
```

The website will be available in: http://localhost:5173
